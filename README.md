EasySubs is a powerful browser extension designed to make language learning natural and enjoyable through immersive content. By integrating directly into popular streaming services, it provides the tools you need to build your vocabulary without breaking your flow.

## 🚀 Key Features

- **Multi-Service Integration:** Works seamlessly with YouTube, Netflix, Coursera, KinoPub, and more.
- **Instant Translation:** Hover over any word to see its meaning instantly. Click to translate the entire phrase.
- **Smart Auto-Pause:** The video automatically pauses when you hover over subtitles, allowing you to learn at your own pace.
- **Learning Service Export:** Save new words directly to Anki, LinguaLeo, or Puzzle English with a single click.
- **Subtitle Navigation:** Effortlessly jump between sentences using arrow keys or the dedicated subtitle progress bar.
- **Customizable Experience:** Adjust subtitle appearance, position, and timing. You can even upload your own SRT or VTT files.

## 🛠️ Installation

### Chrome Web Store
The easiest way to get started is to install EasySubs directly from the [Chrome Web Store](https://chrome.google.com/webstore/detail/easysubs/ocelmccppkcibiflhhepafdjjomimddf).

### Manual Installation (Development)
1. **Prerequisites:** Node.js 20+ and `pnpm`.
2. **Clone the Repo:** `git clone https://github.com/Nitrino/easysubs.git`
3. **Install Dependencies:** `cd easysubs && pnpm install`
4. **Build:** `pnpm build`
5. **Load in Browser:** 
   - Open `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked" and select the `dist` folder.
